# CGV 좌석 탐색 자동화 (CGV Seat Monitor)

CGV 좌석 선택 페이지의 반복 확인을 줄이기 위해 만든 개인 브라우저 자동화 프로젝트입니다. 열린 좌석 페이지를 주기적으로 확인하고, 설정한 조건에 맞는 2연석을 찾으면 좌석 선택과 결제 화면 진입까지 이어지는 흐름을 구현했습니다.

> 테스트 기간에 실제 취소표가 발생하지 않아 취소표 확보까지의 End-to-End 성공은 확인하지 못했습니다. 구현 완료와 실제 예매 성공을 구분해 기록합니다.

## 주요 기능

- 열린 CGV 좌석 선택 페이지 감지
- 새로고침 후 일반 2인 선택 상태 복원
- E열 이후의 연속된 2연석 탐색
- 중앙과 가까운 좌석 조합 우선 선택
- 좌석 선택부터 결제 화면 진입까지의 DOM 이벤트 자동화
- 단일 탭 및 멀티 탭 모니터링
- 실행 로그와 좌석 발견 알림

## 동작 방식

1. AppleScript로 Chrome의 좌석 선택 탭을 찾습니다.
2. 페이지에 JavaScript를 주입해 좌석 상태와 관람 인원을 확인합니다.
3. 조건에 맞는 좌석 후보를 행·번호 기준으로 정렬합니다.
4. 가장 중앙에 가까운 2연석을 선택하고 결제 화면 진입을 시도합니다.
5. 기본 5초 이상의 간격으로 다음 확인을 수행합니다.

멀티 탭 실행은 서버 부하와 실행 안정성을 고려해 최대 4개 탭으로 제한합니다. `CGV_POLL_INTERVAL_MS` 환경 변수로 확인 간격을 늘릴 수 있으며, 5초 미만의 값은 적용되지 않습니다.

## 파일 구성

- `start_monitor.js`: 현재 활성화된 좌석 선택 탭을 모니터링하는 Node.js 실행기
- `start_multi_monitor.js`: 좌석 선택 탭을 최대 4개까지 순회하는 Node.js 실행기
- `monitor.py`: Python 기반 단일 탭 모니터
- `cgv_fast_instant_run.js`: 브라우저 내 좌석 탐색·선택 로직
- `run_live_booking.js`: 활성 Chrome 탭에 실행 로직을 주입하는 스크립트
- `cgv_imax_booking.js`, `cgv_imax_daemon.js`: 초기 구현과 실행 방식 실험 코드
- `tools/`: DOM·이벤트·좌석 상태 확인용 진단 스크립트

## 실행 방법

Chrome에서 CGV 좌석 선택 페이지를 연 뒤 실행합니다.

```bash
# 단일 탭
node start_monitor.js

# 멀티 탭(최대 4개)
node start_multi_monitor.js

# 확인 간격을 10초로 늘리는 예시
CGV_POLL_INTERVAL_MS=10000 node start_multi_monitor.js
```

Chrome에서 AppleScript의 JavaScript 실행 권한이 필요할 수 있습니다. CGV 화면 구조나 클래스명이 변경되면 선택자도 함께 수정해야 합니다.

## 검증 범위와 제한

- 좌석 상태 확인, 관람 인원 복원, 2연석 우선순위 계산, 결제 화면 이동 로직을 단계별로 확인했습니다.
- 최대 12개 탭 순회 동작을 실험했으며, 현재 버전은 최대 4개로 제한했습니다.
- 실제 취소표가 발생하지 않아 실제 예매 성공은 검증하지 못했습니다.
- 사이트 변경, 로그인 상태, 팝업 구조에 따라 자동화가 중단될 수 있습니다.

## 유의사항

이 프로젝트는 개인 학습과 반복 작업 개선을 위한 실험입니다. 서비스 약관과 운영 정책을 확인하고, 서버에 부담을 주지 않는 주기로 사용해야 합니다. 자동화 결과와 실제 예매 성공을 보장하지 않습니다.
