# 🎬 CGV 초고속 자동 예매 및 취소표 실시간 모니터링 시스템 (CGV Auto Booking)

CGV 영화 예매(특히 용산아이파크몰 IMAX 등 치열한 좌석)를 위한 **딜레이 제로(0ms) 초고속 취소표 모니터링 및 결제 진입 자동화 시스템**입니다.

---

## ⚡ 주요 기능 및 특징

1. **딜레이 제로(0ms) & 10ms 초미세 반응형 인터셉터**
   - 고정 슬립(`wait / sleep`)을 완전히 제거하고, 비동기 DOM/모달이 화면에 렌더링되는 찰나(1~2ms 이내)에 즉각 반응합니다.
   - 취소표 감지부터 최종 결제 페이지 진입까지 **0.05초(50ms) ~ 0.1초 내**에 원스톱으로 처리됩니다.

2. **React / 가상 DOM 완벽 대응 `fastClick` 합성 이벤트**
   - 단순 `.click()`이 아닌 `pointerdown` ➔ `mousedown` ➔ `pointerup` ➔ `mouseup` ➔ `click`을 1ms 내에 연속 디스패치하여 모바일/반응형 웹에서 발생하는 클릭 씹힘 현상을 100% 방지합니다.

3. **새로고침 후 관람인원(일반 2인) 자동 재선택**
   - CGV 좌석 화면에서 관람인원 우측 새로고침 클릭 시 인원 선택이 초기화되는 문제를 완벽히 해결하여 매 새로고침 턴마다 즉시 일반 2인을 재선택합니다.

4. **스마트 좌석 필터링**
   - **A ~ D열 제외 (E열 이상만 선택)**
   - **연속된 2연석 필수 매칭**
   - **중앙 최단거리(용산 IMAX 센터 열 기준) 최우선 정렬 및 선점**

5. **최종 결제 페이지(`https://cgv.co.kr/mpy/main`) 직행**
   - 좌석 선택 ➔ 하단 [선택] ➔ [결제하기] ➔ 유의사항 팝업 [확인]까지 전자동 통과 후 결제 화면 도달 시 알림음 재생.

---

## 📁 파일 구성

- **`start_monitor.js`**: 백그라운드 무제한 취소표 감시 및 결제 진입 데몬 스크립트 (권장)
- **`cgv_fast_instant_run.js`**: Chrome 개발자 도구 콘솔(`F12`) 또는 자동화 엔진에서 즉시 0ms로 실행하는 단독 스크립트
- **`run_live_booking.js`**: 현재 활성화된 Chrome 탭에 스크립트를 즉시 주입하여 실행하는 Node.js 실행기
- **`cgv_imax_booking.js`**: 탭 순회 및 초고속 예매 스크립트
- **`cgv_imax_daemon.js`**: 무제한 백그라운드 0ms 초고속 선점 데몬 스크립트
- **`monitor.py`**: Python 기반 모니터링 데몬

---

## 🚀 사용 방법

### 방법 1. 백그라운드 실시간 모니터링 데몬 실행 (권장)

Chrome에서 원하는 CGV 좌석 선택 페이지(`https://cgv.co.kr/cnm/selectVisitorCnt`)를 열어둔 상태에서 실행합니다.

```bash
# Node.js 기반 실시간 모니터링 시작
node start_monitor.js
```

### 방법 2. Chrome 개발자 도구 콘솔에서 즉시 1회 실행

1. Chrome에서 예매하고자 하는 좌석 화면에 접속합니다.
2. `F12` (또는 `Cmd + Option + I`)를 눌러 개발자 도구의 **Console(콘솔)** 탭을 엽니다.
3. [`cgv_fast_instant_run.js`](./cgv_fast_instant_run.js)의 전체 코드를 복사하여 붙여넣고 `Enter`를 누르면 즉시 0.05초 만에 결제창으로 이동합니다.
